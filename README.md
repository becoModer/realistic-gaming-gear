# Realistic Gaming Gear — V1.0 (Forge 1.20.1)

Mouse, keyboard, mousepad and desk blocks for building a gaming setup in Minecraft.

## What's inside (25 blocks)

| Group | Blocks |
|---|---|
| Mice (6) | Basic, RGB, Lightweight (honeycomb), Pro, Wireless (with dongle), Ultra |
| Keyboards (9) | 60%, 65%, TKL, Full-size, Custom, RGB Mechanical, White, Black, Transparent |
| Mousepads (6) | Black, White, Red, Blue, Purple, RGB |
| Desks (4) | Wooden, Black, White, RGB |

All items are in the creative tab **Realistic Gaming Gear** and have crafting recipes.

## How to use in-game

- Place mice, keyboards and mousepads on top of a **desk** (they need a full, flat surface under them).
- They face you when placed. **Right click** = rotate 90° (plus a click sound).
- **Sneak + right click** on an RGB item = turn the RGB light on/off (animated rainbow texture + light level).
- **Right click** on the RGB desk = toggle its under-desk light strip.

## Build it

You need **JDK 17**. Easiest way:

1. Download the **Forge 1.20.1 MDK (47.3.0)** from https://files.minecraftforge.net/ and unzip it.
2. Copy these from this project over the MDK, replacing what is there:
   `src/`, `build.gradle`, `gradle.properties` (keep the MDK's own `gradlew`, `gradle/` and `settings.gradle`).
3. In the MDK folder run `./gradlew build` (Windows: `gradlew build`).
4. The mod is `build/libs/realisticgaminggear-1.0.0.jar` — put it in your `mods` folder with Forge 1.20.1.

To test without building a jar: `./gradlew runClient`.

## Changing textures / models

Everything visual is generated by `tools/gen_assets.py` (needs `pip install pillow`).
Edit it and run `python3 tools/gen_assets.py` — it rewrites all textures, models,
blockstates, lang, loot tables and recipes. Block names in the script must match
`ModBlocks.java`. You can also open the generated models in Blockbench and refine them.
